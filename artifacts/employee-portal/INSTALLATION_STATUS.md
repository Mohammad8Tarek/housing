```bash

npm install
npm run preview
```

```

```

### خطوة 2: على هاتفك

#### 📍 احصل على IP الكمبيوتر:

**Windows:**
```
ipconfig → IPv4 Address: 192.168.x.x
```

**Mac/Linux:**
```
ifconfig → inet 192.168.x.x
```

---

#### 📱 افتح المتصفح على الهاتف:

```
http://192.168.1.100:10000
```
*(استبدل 192.168.1.100 بـ IP الحقيقي)*

## 🔧 حل سريع للمشاكل

### "لم تظهر رسالة التثبيت"

**جرّب:**
1. أعد تحميل الصفحة (Refresh)
2. افتح tab جديد واكتب العنوان من جديد
3. انتظر ثانية واحدة كاملة

### "يفتح في المتصفح وليس تطبيق"

**السبب:** الـ manifest لم يحمّل بشكل صحيح

**الحل:**
1. اضغط F12 (DevTools)
2. اذهب **Application** → **Manifest**
3. يجب أن يقول: `✓ Manifest loaded successfully`

### "الأيقونة ضعيفة أو غير واضحة"

**التوقع:** الأيقونة يجب أن تكون حادة وواضحة

**الحل:**
- على Android: تأكد من أن Chrome هو المتصفح
- على iOS: قد تأخذ وقت أكثر لتحميل الأيقونة

## 📞 نصائح للأداء الأفضل

1. **استخدم نفس الشبكة (Wi-Fi)**
   - الكمبيوتر والهاتف على نفس الـ Wi-Fi

2. **اختبر على جهازين مختلفين**
   - iOS: Safari مع "Add to Home Screen"
   - Android: Chrome مع "Install app"

3. **للاختبار على الأجهزة:**
   - الهاتف: أجهزة فعلية أفضل
   - المحاكاة: تعمل لكن بطيئة

4. **للأداء الأسرع:**
   - امسح cache المتصفح الأول مرة
   - بعدها كل شيء يفتح من الذاكرة المحلية
