## 📱 خطوات التثبيت الدقيقة

### **1️⃣ تشغيل التطبيق محلياً:**

```bash
cd artifacts/employee-portal

# تثبيت المكتبات
npm install

# بناء الإصدار النهائي
npm run build

# تشغيل الخادم
npm run preview
```

**الخادم سيشتغل على:** `http://localhost:10000`

---

### **2️⃣ على هاتف آيفون (iOS):**

#### ✅ **الطريقة 1: Share Menu (الأفضل)**

1. افتح **Safari** على الآيفون
2. اكتب في العنوان: `http://localhost:10000`
   - **لو على شبكة مختلفة:** `http://192.168.x.x:10000`
3. انتظر **ثانية واحدة** لتحميل الصفحة كاملة
4. اضغط **مشاركة** (Share ↗️ من الأسفل)
5. اختر **"إضافة إلى الشاشة الرئيسية"**
   - إذا لم تري الخيار = الـ manifest لم يحمّل بعد
6. اضغط **"إضافة"** بجانب اسم التطبيق
7. **تم!** ستجد أيقونة على الشاشة الرئيسية ✨

#### ✅ **الطريقة 2: Install Banner (تلقائية)**

- قد تجد **رسالة تثبيت تلقائية** في الأسفل
- اضغط عليها مباشرة

---

### **3️⃣ على هاتف أندرويد (Samsung, Xiaomi, إلخ):**

#### ✅ **الطريقة 1: Chrome Install Prompt (الأفضل)**

1. افتح **Google Chrome**
2. اكتب في العنوان: `http://localhost:10000`
   - **لو على شبكة مختلفة:** `http://192.168.x.x:10000`
3. سترى **رسالة تثبيت أسفل الشاشة** مثل:
   ```
   [↓] Sunrise Portal
   "تثبيت" [✓]
   ```
4. اضغط **"تثبيت"**
5. انتظر ثانية واحدة
6. **تم!** التطبيق موجود الآن في درج التطبيقات 📲

#### ✅ **الطريقة 2: Menu Installation**

إذا لم تظهر الرسالة:

1. اضغط **القائمة (☰)** في Chrome
2. اختر **"تثبيت التطبيق"** أو **"Install app"**
3. اضغط **"تثبيت"** في الرسالة التي تظهر

#### ✅ **الطريقة 3: Add to Home Screen (الطريقة القديمة)**

إذا لم تعمل الطريقتان:

1. اضغط **القائمة (☰)**
2. اختر **"إضافة إلى الشاشة الرئيسية"**

## 🌐 الوصول من شبكة محلية (Wi-Fi)

إذا كنت تريد تثبيت التطبيق على هاتفك الفعلي:

### **الخطوة 1: احصل على IP الكمبيوتر**

**على Windows:**

```bash
ipconfig
```

ابحث عن: `IPv4 Address: 192.168.x.x`

**على Mac/Linux:**

```bash
ifconfig
```

ابحث عن: `inet 192.168.x.x`

### **الخطوة 2: تأكد من أن الهاتف وحسوبك على نفس الـ Wi-Fi**

### **الخطوة 3: في المتصفح على الهاتف اكتب:**

```
http://192.168.1.100:10000
```

_(استبدل الأرقام بـ IP الحقيقي)_

### **الخطوة 4: ثبّت التطبيق بالخطوات أعلاه**

## 🧪 اختبر التثبيت الصحيح

بعد التثبيت، تحقق من:

### ✅ **علامات النجاح:**

- [ ] التطبيق يفتح **بدون شريط العناوين**
- [ ] الأيقونة تظهر على الشاشة الرئيسية
- [ ] اسم التطبيق هو "Sunrise Portal"
- [ ] لون الخلفية أسود
- [ ] يفتح من الشاشة الرئيسية مباشرة
- [ ] يعمل **بدون انترنت** (بعد أول فتح)

### ❌ **علامات المشكلة:**

- لم تظهر رسالة تثبيت
- يفتح داخل المتصفح (بشريط العناوين)
- الأيقونة لا تظهر على الشاشة الرئيسية

## 🐛 حل المشاكل الشائعة

### ❓ **المشكلة: لم تظهر رسالة التثبيت**

**الحل:**

1. أعد تحميل الصفحة (Refresh)
2. افتح الصفحة من صفر (جديد)
3. تأكد من أن الـ Service Worker مسجل:
   - اضغط F12 → Application → Service Workers
   - يجب أن يقول "activated and running"

### ❓ **المشكلة: يفتح في المتصفح وليس تطبيق**

**الحل:**

- تأكد من أن `display: standalone` موجود في manifest.json ✓

### ❓ **المشكلة: الأيقونة صغيرة أو غير واضحة**

**الحل:**

- استخدم PNG بدلاً من SVG (قد تكون الأيقونات SVG لا تعمل على كل الأجهزة)

### ❓ **المشكلة: الانترنت مقطوع والتطبيق لا يعمل**

**الحل:**

- زر التطبيق مرة واحدة حتى يحفظ البيانات محلياً
- ثم يعمل بدون انترنت
