# 🚀 خطوات التثبيت السريعة - Employee Portal

## ⚡ 5 خطوات فقط للتثبيت على أي هاتف

### 1️⃣ شغّل الخادم

```bash
cd artifacts/employee-portal
npm install
npm run preview
```

👉 **الخادم يعمل الآن على:**

```
http://localhost:10000
```

---

### 2️⃣ على هاتفك - استخدم نفس الشبكة

**احصل على IP الكمبيوتر:**

```bash
# Windows
ipconfig

# Mac/Linux
ifconfig
```

ابحث عن: `192.168.x.x`

---

### 3️⃣ اكتب العنوان في المتصفح

```
http://192.168.x.x:10000
```

_(استبدل الأرقام بـ IP الحقيقي)_

---

### 4️⃣ رسالة التثبيت ستظهر تلقائياً!

#### 🍎 **iOS (آيفون):**

- إذا لم تظهر رسالة:
  - اضغط **مشاركة** ↗️
  - اختر **"إضافة إلى الشاشة الرئيسية"**

#### 🤖 **Android:**

- سترى رسالة "تثبيت" أسفل الشاشة
- اضغط **"تثبيت"** مباشرة

---

### 5️⃣ تم! ✨

التطبيق الآن:

- ✅ في درج التطبيقات
- ✅ يفتح بدون شريط العنوان
- ✅ يعمل بدون انترنت
- ✅ يحدّث نفسه تلقائياً

## 🆘 لو ما ظهرت رسالة التثبيت؟

### حاول هذا:

1. **أعد تحميل الصفحة** (Refresh)

   ```
   اضغط F5 أو اسحب لأسفل
   ```

2. **افتح الصفحة من جديد**
   - أغلق المتصفح تماماً
   - افتحه من جديد

3. **تحقق من الـ Service Worker:**
   - اضغط F12 (DevTools)
   - اذهب لـ **Application**
   - في **Service Workers** يجب أن يقول:
     ```
     ✓ activated and running
     ```

4. **استخدم Chrome على Android:**
   - Chrome يظهر رسالة التثبيت تلقائياً
   - المتصفحات الأخرى قد تكون أبطأ
